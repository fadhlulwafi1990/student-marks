Teacher / Admin Setup Guide

To use live data from OneDrive instead of the mock fallback, follow these steps:

  1. Create an Excel file with columns: Matrix, Name, and Mark.
  2. Save it as a CSV (Comma delimited) file in your OneDrive.
  3. Right-click the CSV in OneDrive online and click Embed (or generate a sharing link).
  4. Extract the direct download URL. A standard OneDrive link looks like this:
    https://onedrive.live.com/download?cid=YOUR_CID&resid=YOUR_RESID&authkey=YOUR_AUTHKEY
  5. Paste that URL into the ONEDRIVE_CSV_URL variable in the JavaScript section of this file.

Important: Browsers block cross-origin requests (CORS). Direct links to OneDrive often fail in pure client-side JavaScript. If the live link fails, this app will automatically fall back to the built-in MOCK_DATA so the UI keeps working. For a robust production setup, consider publishing a Google Sheet to Web (CSV format) which has better CORS support, or host the CSV on the same domain as this HTML file.
